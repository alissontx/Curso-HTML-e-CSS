Antes do download propriamente dito, cabe ressaltar o que são Media Types (ou tipos de mídia) que são uma forma de identificar qual tipo de conteúdo está sendo transmitido ou solicitado na web. No contexto de HTML, CSS e desenvolvimento web, eles são especialmente importantes porque permitem dizer ao navegador para qual tipo de mídia ou formato uma regra deve ser aplicada. Clique em Media Types e seja encaminhados ao site oficial com lista de Media types

Efetuando download:

Para efetuar download basta colocar um link e complementar com : dowload= "nome do arquivo que deseja baixar" type= "atalho disponivel no site acima - chamados midiatypes"

Precisa ter o arquivo baixado na pasta ou subpasta que o arquivo HTML está.
