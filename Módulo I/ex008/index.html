Semântica em HTML

HTML também é conhecido como Linguagem semântica, que signfica dizer que cada elemento tem um significado específico,logo, na HTML algumas tags foram introduzidas e substituidas para melhor representar o significado dos elementos;

Atalho importante: Ctrl + Shift + P
Aqui cria-se um atalho com foco na simplificação.

Funcionou

Negrito e destaque

A antiga tag <b> que servia para sublinhar e negritar foi subtituida pela tag <strong> que serve para informar que essa suposta oração é forte;
Exemplo: Atenção! - A palavra Atenção! é forte e deve ser enfatizada;

Itálico e ênfase

Ainda a antiga tag <i> (não semantica) foi substituída pela tag <em> que serve para informar que essa suposta oração é enfatizada;
Exemplo: Importante! - A palavra Importante! é enfatizada em itálico

Marcador de texto

Podemos marcar o texto com a tag <mark>: Este é um texto marcado

Para mudar de cor faz-se necessário utilizar CSS dentro da tag <mark> coloque um elemento chamado <style>
Fica assim: <mark style="background-color: red; color: black;">Este é um texto marcado</mark>

Esse texto está marcado

Uma segunda alternativa é criar uma tag chamada <style> ; alterando todos os marcadores para a cor desejada

Texto grande e texto pequeno

As tags <big> nçao tem subtituição pois tamanho é estilo e estilo se faz com CSS, já as tags <small> até o momento continua a ser utilizada;

Texto excluído e texto inserido

Para indicar que um texto foi excluído, utiliza-se a tag <del>: Este é um texto excluído

Para indicar que um texto foi inserido, utiliza-se a tag <ins>: Este é um texto inserido

Texto subscrito e texto sobrescrito

Para indicar que um texto é subscrito, utiliza-se a tag <sub>: Este é um texto subscrito

Exemplo: H<sub>2</sub>O - Água: H2O

Para indicar que um texto é sobrescrito, utiliza-se a tag <sup>: Este é um texto sobrescrito

Exemplo: X<sub>2</sub>*3: X2*3
