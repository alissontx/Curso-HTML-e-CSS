Outras formatações

Código-fonte e pré-formatada

Para exibir código-fonte ou texto pré-formatado, você pode usar as tags <pre> e <code>.
A tag <pre> preserva espaços e quebras de linha, enquanto a tag <code> é usada para marcar trechos de código.

        
            function saudacao() {
            console.log("Olá, mundo!");
            }

function saudacao() { console.log("Olá, mundo!"); }

Citações

Citação simples

Para inserir uma citação simples, você pode usar a tag <q>. Por exemplo:

Existe uma frase famosa de Sócrates, onde ela afirma:É provável que eu seja mais sábio do que ele, ao menos neste pequeno ponto: não penso saber aquilo que não sei.

Citação direta ou em blocos

Para inserir uma citação, você pode usar a tag <blockquote>. Por exemplo:

É provável que eu seja mais sábio do que ele, ao menos neste pequeno ponto: não penso saber aquilo que não sei.

Abreviações

Para inserir uma abreviação, você pode usar a tag <abbr>. Por exemplo:

O ONU é uma organização internacional.

HTML é uma linguagem de marcação.

CSS é uma linguagem de estilo.
