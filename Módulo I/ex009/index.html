Lista de definição

Termo
definição

HTML
HTML (HyperText Markup Language), ou Linguagem de Marcação de Hipertexto, é a linguagem de marcação utilizada para estruturar e organizar o conteúdo de páginas da web. Diferentemente de uma linguagem de programação, o HTML é uma linguagem de marcação, responsável por definir a estrutura e a organização dos elementos de uma página.

CSS
CSS (Cascading Style Sheets) é uma linguagem usada para definir a aparência de uma página da web. Com ela, é possível alterar cores, fontes, tamanhos, espaçamentos e a organização dos elementos. Enquanto o HTML cria o conteúdo da página, o CSS deixa esse conteúdo mais bonito, organizado e adequado para diferentes dispositivos, como computadores, tablets e celulares.

JavaScript
JavaScript é uma linguagem de programação usada para tornar as páginas da web interativas e dinâmicas. Com ela, é possível criar funcionalidades como botões que respondem ao clique, formulários com validação, animações, menus interativos e atualização de informações sem precisar recarregar a página. Enquanto o HTML estrutura o conteúdo e o CSS define a aparência, o JavaScript adiciona comportamento e interação ao site.
